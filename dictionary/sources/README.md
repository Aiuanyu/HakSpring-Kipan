# sources/

Per-source dictionary inputs discovered by the pipeline. Each `<category>/<key>/`
holds one `config.yaml` + `data/raw/<original>` + the canonical `data/<key>.csv`
that `./run.sh` produces, and a `README.md` on the source's quirks.

Source keys, categories and bits: [`../README.md` § Sources](../README.md#sources-english-key--chinese--category).
URLs, licences and capture dates: [`../docs/SOURCES.md`](../docs/SOURCES.md).
