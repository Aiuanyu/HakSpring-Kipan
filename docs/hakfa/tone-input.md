# 客源翠企盤聲調輸入指南 (Tone Input Guide)

客源翠企盤支援桌面版「**按鍵修飾打調**」機制：**純數字鍵 `1～9` 永遠保留給候選字擇字**，打調時使用 **`⌃`（Control）＋數字**，兼顧快速擇字與精準限調。

可在系統「設定 → 聲調輸入方案」中切換以下兩種方案：

---

## 一、符號編號（預設推薦）

與臺羅／白話字通用調符編號一致，**無須記憶各腔調值，跨腔通用直觀**：

| 快速鍵 | 對應調符 | 符號名稱 | 範例（海陸） | 範例（四縣） |
|---|---|---|---|---|
| `⌃2` | `á` | 尖音（acute） | `da` + `⌃2` → `dá`（打） | `da` + `⌃2` → `dá`（單） |
| `⌃3` | `à` | 低音（grave） | `sin` + `⌃3` → `sìn`（新） | `da` + `⌃3` → `dà`（大） |
| `⌃5` | `â` | 折音（circumflex） | `deu` + `⌃5` → `dêu` | `deu` + `⌃5` → `dêu` |
| `⌃6` | `ǎ` | 抑音（caron） | `si` + `⌃6` → `sǐ`（細） | `si` + `⌃6` → `sǐ`（死） |
| `⌃7` | `ā` | 平音（macron） | `sii` + `⌃7` → `sīi`（事） | — |

### 操作特性：
1. **無標調**：不想限定調時，無調符音節直接輸入字母即可（如海陸 `sii`），候選會列出所有調。要**限定在無標調**，按 `⌃1`（入聲音節 `⌃4`，兩個鍵打哪個都照音節種類換）：畫面維持無標，候選只剩無標調的字（如 `dam` + `⌃1` 只剩 `擔` 的無標讀音）。
2. **換調即時替換**：輸入調號後若欲更改，直接按另一組 `⌃+數字` 即可就地替換（如 `⌃2` 改按 `⌃3`，`dá` 立刻變 `dà`）。
3. **清除調符**：按 `Backspace` 即可刪除當前音節之調符，回復為無標狀態。

---

## 二、五度調值

適合習慣以五度音高（如 `24`、`33`、`53`）思考的使用者。系統會依當前選擇之腔調（四縣、南四縣、海陸）動態換算：

### 1. 舒聲（兩位數連續敲鍵）
連續按下兩次 `⌃+數字`，湊成兩位數調值後立即成調：

- **四縣／南四縣**：
    - `⌃2` `⌃4` → `á`（24 陰平）
    - `⌃3` `⌃1` → `à`（31 陰去）
    - `⌃1` `⌃1` → `ǎ`（11 陽平）
    - `⌃5` `⌃5` → 無標（55 去聲）：畫面維持無標，候選限定在無標調
- **海陸**：
    - `⌃3` `⌃3` → `ā`（33 陽去）
    - `⌃5` `⌃3` → `à`（53 陰平）
    - `⌃2` `⌃4` → `á`（24 陰去）
    - `⌃1` `⌃1` → `ǎ`（11 陽舒）
    - `⌃5` `⌃5` → 無標（55 陽平）：畫面維持無標，候選限定在無標調

> **緩衝機制**：按下第一位數字時暫存於內部狀態，不污染畫面；第二位輸入完成即動態轉為對應調符。若中途輸入其他字母或按鍵，前置數字自動取消。

### 2. 入聲（塞音韻尾 `b, d, g`）
入聲韻尾音節為單數字一鍵成調：
- `⌃2` → 陰入（如四縣 `fad` + `⌃2` → `fàd`）
- `⌃5` → 陽入
