## 三、 模組耦合程度評估（Coupling Matrix）

- **完全獨立（零修改直接沿用）**：
  - `engine/mmap-host/`：記憶體對映純底層，零語言耦合。
  - `engine/swift-ffi/`：C FFI 通訊封裝，零語言耦合。
  - `engine/ranking/`：排序評分器，主要比對詞頻與使用者點擊記錄，無寫死拼音。
  - `engine/protos/`：Protobuf 訊息格式，通用字串傳遞。
- **輕度耦合（大多可沿用）**：
  - `engine/composing/`：Lattice 格狀圖與 Viterbi 尋優演算法是通用的，只需確保給入的音節與代價正確。
  - `engine/lexicon/`：FST 前綴查表與 binary 讀取，只要二進位結構符合 TKDB v3 即可零修改運作。
- **重度耦合（需實作客話 Profile）**：
  - `engine/phonetics/`：所有的聲韻調合法性檢查、音節切分走訪與簡拼提取皆在此處。
