# Rust shared-core artefacts

`RustTaigi.xcframework` and `RustTaigi.swift` are regenerated by
`engine/scripts/build-xcframework.sh` (release) or
`engine/scripts/build-xcframework.sh --dev` (dev / tests with panic-injector).

Do not edit manually. Only this README is tracked: the xcframework and the
bridge sources (`RustTaigi.swift`, `SwiftBridgeCore.swift`) are gitignored and
generated by `make ios-libs` at the repository root (`make build` runs it). The
directory itself stays so Xcode source references are stable across a fresh
clone.

The xcframework wraps `engine/swift-ffi`; its exported surface is the `mod ffi`
bridge block in `engine/swift-ffi/src/lib.rs` (`process_request_bytes` is the one
request entry point; `panic_for_test` panics only in the `--dev` build).
